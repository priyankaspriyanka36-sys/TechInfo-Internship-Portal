# TechInfo Internship Portal

## 📌 About
A web-based internship application portal developed using Python, Flask, HTML, CSS, and MySQL.

## ✨ Features
- Student Registration
- Internship Application Form
- Course, Year & Semester Selection
- Resume Upload
- Responsive Design

## 🛠 Technologies Used
- Python
- Flask
- HTML5
- CSS3
- MySQL
- phpMyAdmin

## 🚀 How to Run
1. Clone the repository
2. Install Flask:
   pip install flask
3. Run:
   python app.py
4. Open:
   http://localhost:5000
